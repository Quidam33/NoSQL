## Цель работы

Целью работы является разработка распределенной базы данных с использованием шардинга и проведение нагрузочного тестирования системы.

## Проектирование базы данных

База данных предназначена для хранения информации о студентах университета.
Выбрана документная база данных MongoDB, тк она хорошо подходит для хранения подобных документов.

## Коллекции БД

В БД с информацией о студентах используются следующие коллекции:
- students
- faculties
- groups
- courses
- grades

}


## Реализация шардинга

Шардинг используется для горизонтального масштабирования базы данных, а именно - для распределения данных между несколькими серверами и таким образом увелиения производительности системы.
В работе используется Hashed shard key.

Шардируемые коллекции - students, grades
Ключ шардигования - _id

Почему выбрано:
- Равномерное распределение данных
- Простота настройки
- Масштабируемость


### Настройка шардинга

- sh.enableSharding("university_db")
- sh.shardCollection("university_db.students", {"_id": "hashed"})
- sh.shardCollection("university_db.grades", {"student_id": "hashed"})


## Интерфейс на Python

Реализованный консольный интерфейс на Python с использованием pymongo предоставляет следующий функционал:
1 - Добавление студента
2 - Поиск студента 
3 - Просмотр студентов группы 
4 - Добавление оценок 
5 - Просмотр оценок


## Нагрузочное тестирование

Нагрузочное тестирование выполнено с помощью массовой вставки студентов и массвого чтения студентов по их ID. В качестве метрик использованы:
- Время выполнения операций 
- Количество операций

Результаты показали, что использование шардинга позволяет распределить нагрузку и повысить масштабируемость системы.
